# Как запустить сервер

Для запуска нужны:
- Nim версии 2.2.10 или новее и компилятор C (MinGW).

Открой терминал в корне проекта и выполни:

```sh
atlas install
nim runServer
```

Оставь терминал открытым во время игры. Для остановки сервера нажми `Ctrl+C`.

При следующих запусках достаточно:

```sh
nim runServer
```
